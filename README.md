AI-Based Medical System for Shoulder Fracture Detection and Exercise Guidance

This repository contains the code and resources for a Final Year Project that demonstrates an AI-powered medical system. The system is designed to detect shoulder fractures, generate medical reports, and guide patients through rehabilitation exercises using AI technologies.

🩺 Project Overview

The AI-based medical system performs the following tasks:

Shoulder Fracture Detection

Detects the type of shoulder fracture from medical images using the YOLOv8 object detection model.

Classifies fractures accurately to assist medical professionals in diagnosis.

Automated Report Generation

Generates detailed, structured medical reports based on the detected fracture.

Uses Google Gemini to convert AI findings into natural language reports.

Pose Estimation for Exercise Guidance

Tracks patient movements using MediaPipe and OpenEV for pose estimation.

Provides real-time feedback to ensure correct execution of prescribed rehabilitation exercises.

Video Demonstration

Combines all AI functionalities into a visual demo for easy presentation.

Text overlays in the video describe each step of the process for clarity and visual appeal.

🛠️ Technologies Used

YOLOv8 – Real-time object detection for fracture classification

Google Gemini – Natural language processing for report generation

MediaPipe – Human pose detection and tracking

OpenEV – Exercise guidance and movement analysis

Python – Backend and AI scripting

Video Editing – AI-generated text overlays for demonstration
